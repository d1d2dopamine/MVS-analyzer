## Boundaries

This is not an atomic multi-file save or hostile-host sandbox. A concurrently changed observed file can be omitted after re-verification; a successful computation does not certify a permanently complete output directory. Resumed manifest producers use their existing freshly generated child folder; they have not been redesigned against concurrent file injection. Untracked benchmark and state-check paths retain their previous listing/read-existing semantics. Plugin paths returned after successful plugin export follow the existing observer contract; plugin exceptions do not retroactively identify unreported files.

Statistical formulas, random streams, checkpoint arithmetic and scientific readiness are unchanged. Actual Windows acceptance remains pending. Historical source-provenance gaps recorded in Round35 are preserved; the new reviewed transition does not supply missing historical evidence.
