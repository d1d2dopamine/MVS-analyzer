# Round35: исправлены устаревшие проверки исходников

## Результат

Старый Colab-набор теперь проходит **48/48**, а проверки исходников интерфейса — **18/18**. До исправления они сообщали об изменении 17 файлов, потому что ожидаемые хеши отстали от уже выпущенных изменений. Добавлены **24 проверки самого защитного механизма**, включая намеренно испорченные файлы и описания версий; все прошли.

Просто подставить нынешние хеши означало бы скрыть возможную ошибку. Поэтому для каждого файла отдельно сверены доступные версии, изменения и документы. Оба первоначальных файла с историческими хешами сохранены побайтно. Новые разрешённые версии записаны отдельным слоем: первоначальный хеш → прежний ожидаемый хеш → отдельно рассмотренный текущий хеш, с причиной и ссылками на доказательства.

## Где история подтверждена, а где остаётся пробел

Для 13 файлов восстановлена цепочка от прежнего ожидаемого состояния до нынешнего. Для 4 файлов часть старых переходов отсутствует: обработчик CLI-аргументов, проект CLI, HeadlessRun и ScientificCommands. Их текущее поведение дополнительно рассмотрено отдельно, а доступные архивы и более поздние изменения сверены.

Старое необъяснённое расхождение HeadlessRun, отмеченное ещё в отчётах 4/8, **не объявлено объяснённым**. Теперь явно принят рассмотренный текущий исходник; недостающая история не выдумана. Подробности есть в английском техническом отчёте и в новом манифесте.

## Что защищают проверки

Неожиданное изменение защищённого файла по-прежнему приводит к провалу теста. Неизвестный путь, испорченный хеш, пропавший файл описания, повторяющийся JSON-ключ или разорванная цепочка версий не принимаются. Даже Python с оптимизацией `-O` не отключает эти проверки. Тесты также фиксируют точный набор 17 пересмотренных файлов и 4 честно отмеченных исторических пробела.

Это контроль соответствия исходников рассмотренной версии. Он не доказывает научную корректность метода и не мешает владельцу компьютера сознательно переписать одновременно код и его контрольные данные.

## Что осталось прежним

- Производственный C#, Python-обёртка, статистические формулы и вычислительные настройки не изменялись. Новые научные выборки и сравнительные эксперименты не запускались.
- Исправленный в Round34 встроенный Colab-архив сохранён без изменений. Его проверка включена в точный `python tools/check_source.py`.
- README не расширялся техническим журналом.
- Научный NO-GO прежний. Проверка Windows MCP на реальной Windows всё ещё требует ваших результатов.

Новые проверки включены в обычный статический CI. Они выполняют локальные тесты и симуляции, а не настоящий сеанс Google Colab или оконный интерфейс Windows.

## Архив и откат

Полный ZIP содержит исходники всех предыдущих изменений; старые патчи для сборки не нужны. Полные доказательства этапа находятся в `validation/round35-evidence.zip`, машинная сводка — `validation/round35-results.json`. После новой распаковки проверяется точная команда `python tools/check_source.py`.

Для отката сохраните и верните полный Round34. Пользовательские входные файлы и результаты не затронуты; старые предупреждения об устаревших хешах при таком откате вернутся.

Дополнительно заново прошли 152 существующих проверки инструментов и 435 независимых/сохранённых проверок из validation. Нативные результаты в этих проверках взяты из сохранённого Round34, а не выданы за новый запуск C#: производственные файлы побайтно не изменились.
