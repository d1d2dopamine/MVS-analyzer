# MVS: этап 22, локальный протокол и MCP

Готов ограниченный экспериментальный вариант для Linux/облачной машины.
Windows-версия MCP пока не поддерживается. Обычные интерфейсы MVS сохранены;
статистические расчёты не менялись.

Добавлено:

- Явное разделение технического завершения и научного статуса NO-GO в машинном
  ответе существующего CLI.
- Новый mvs-workflow: исследовательский запуск либо запуск по неизменяемой
  локальной записи протокола. Сейчас только summary analyze с готовой калибровкой.
- Привязка к точным копиям данных/калибровки, настройкам и версии движка;
  изменения отклоняются, повтор того же run ID не запускает расчёт заново.
- mvs-mcp через локальный stdio: пять ограниченных инструментов, общие проверки
  с CLI, отмена и лимиты. Используется официальный SDK mcp 1.30.0.

Проверены реальные .NET-расчёты, согласованность CLI/Python/MCP, ошибки входных
данных, неизменяемость записей, повторные запросы, отмена и ограничения путей.
Итог: 144/144 нативных проверки, 490/490 тестов Python без пропусков и 53 случая
независимой сверки со SciPy. В Python входят 35 проверок нового workflow и 14 MCP,
включая реальные вызовы движка. Проверена установка пакета и запуск через
установленную команду. Подробности и ограничения — в round22-results.json и
подробном отчёте. Старые и новые результаты проверок не смешиваются.

Важно: локальная «заморозка» не доказывает предварительную регистрацию, полноту
истории экспериментов или научную достоверность. Калибровка уже существовала до
фиксации протокола; сведения о предыдущем просмотре данных заявляет пользователь.
Все 12 метрик, Bonferroni и научный NO-GO сохранены.

Инструкция запуска: WORKFLOW_PROTOCOL.md. Настройка MCP: LOCAL_MCP.md.
Windows MCP требует отдельного этапа изоляции файлов, блокировок и отмены процессов
с реальными Windows-тестами. Этот архив не следует считать завершением всей
кроссплатформенной первой стадии или готовым научным релизом.
