## Six prespecified conditions, one design

Two independent groups G0,G1, sixteen entities per group, forty measurements per entity (1,280 observations per dataset). Fixed entity ordering G0/E00..E15 then G1/E00..E15, repeats 0..39. Model y_gij=mu_g+tau_g B_gi+sigma_g E_gij. All latent draws independent, except the shared entity intercept within repeats. Parameters below are SDs. G0 always (mu,sigma,tau)=(20,1,1).

- C0 Gaussian global null: G1=(20,1,1). Both component nulls true; complete raw-data distributions equal; legacy global null also true.
- C1 Gaussian location-only variance-null control: G1=(22,1,1). Mean shift +2 (+10% of baseline mean); within/between SD and variance change 0%. Both component nulls true. Legacy global null is false; legacy rejections here are location sensitivity, not false positives.
- C2 Gaussian within-only: G1=(20,2,1). Within SD +100%, variance 1 to 4 (+300%); between change 0%. H_W false, H_B true. Between rejection is a false-component diagnosis.
- C3 Gaussian between-only: G1=(20,1,2). Between SD +100%, variance 1 to 4 (+300%); within change 0%. H_B false, H_W true. Within rejection is a false-component diagnosis.
- C4 Gaussian combined: G1=(20,2,2). Both SDs +100%, both variances +300%. Both component nulls false.
- C5 non-Gaussian equal-distribution assumption stress: G1=(20,1,1), BOTH groups use independent standardized t5 latent intercepts and residuals, each t5 multiplied by sqrt(3/5), so both component variances equal 1. Both component nulls and equal-distribution legacy null true, but Gaussian assumptions fail. Label all Gaussian-reference outputs out-of-model. This is one heavy-tail stress, not a robustness survey.

C0..C4 use standard normal B and E. No truncation, positivity repair, rejection sampling, winsorization, seed search, sample removal, or response-dependent changes. Nonpositive observations are retained; geometric-mean availability follows shipped rules. The twelve-hypothesis correction never shrinks. Fixed large effects aim to reveal gross differences within a small budget, not approximate an MDE or finely resolve practical thresholds.
